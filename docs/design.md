# Design

PollPulse is built around a shared moment: a room waiting to see what everyone thinks.

The presenter screen gives the question the greatest visual weight, keeps controls in a compact toolbar, and uses open space to separate results from joining. Coral marks the main action; pale mint gives the join area a distinct place without competing with the question. On smaller screens, these sections stack and answer targets stay easy to tap.

Plus Jakarta Sans is self-hosted under the SIL Open Font License. The same type family is used for headings, forms, controls, and results. Profile glyphs remain playful while the rest of the interface stays restrained.

The rebuild preserves the original workflow and scoring behavior. It improves lifecycle cleanup, local preview clarity, responsive styling, and QR generation on the device.
